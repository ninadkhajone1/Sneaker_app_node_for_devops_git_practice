# 👟 Sneaker Store App

A simple Node.js web application built as a hands-on practice project while learning **DevOps** fundamentals: Linux, Git & GitHub, and AWS.

The app itself is intentionally small. The goal of this repository is to practice a real **version control workflow** and to serve as the base project for upcoming DevOps work (Docker, CI/CD and AWS deployment).

## 🚀 Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) installed
- [Git](https://git-scm.com/) installed

### Run locally

```bash
# Clone the repository
git clone https://github.com/ninadkhajone1/Sneaker_app_node_for_devops_git_practice.git

# Move into the project folder
cd Sneaker_app_node_for_devops_git_practice/sneaker-store-app

# Install dependencies
npm install

# Start the server
node server.js
```

Then open **http://localhost:3000** in your browser.
<!-- ✏️ Change 3000 to the port used in your server.js -->

## 🔀 Git Workflow Practiced

This repository was used to practice the core Git and GitHub workflow:

- Initialized a repository (`git init`) and checked its state (`git status`)
- Moved files through the lifecycle: untracked → staged → committed (`git add`, `git commit`)
- Connected the local repo to GitHub (`git remote add origin`) and pushed code (`git push`)
- Reviewed history and changes (`git log`, `git diff`)
- Undid changes safely (`git restore`, `git restore --staged`)
- Worked with branches (`git branch`, `git checkout -b`, `git merge`)
- Synced changes with `git pull` and `git clone`
- Used a `.gitignore` to keep unwanted files out of the repo
